# Debilidades del Dataset

1. Ocurre que hay personas que nacieron en un pais, pero han hecho su vida en otro, por lo que en el dataset queda guardado un pais (que es donde ha hecho su vida), pero el modelo responde donde nació.

2. El género es bien diverso, por lo que el modelo nunca va a responder algo exacto a lo que se tiene en el dataset

3. El modelo falla bastante con la editorial, quizas si se hace la pregunta con el ISBN sea mas directo y se pueda mejorar

4. Los años tambien varian por edicion, quizas se deberian haber guardado año por ISBN


# Fortalezas del Dataset

1. El Pais de las personas lo puede responder bien
